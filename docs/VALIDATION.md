`tests/NativeAcceptance` 是显式运行的验收程序，不在普通测试中执行。它在全新目录安装官方旧版 CLI，实际运行版本查询，经公开版 UpdateService 升级并再运行版本查询，最后比较原有安装清单。可同时对已有官方 MSIX 执行 Windows 验签和全块校验；该路径只读，不执行 Windows 部署。

```powershell
dotnet build tests/NativeAcceptance -c Release
& ./tests/NativeAcceptance/bin/Release/net10.0-windows/NativeAcceptance.exe "$PWD/artifacts/native-new"
```

也可以依次提供已有官方 MSIX 路径及前次验收目录作为第二、第三个参数。第三个参数只复用公开安装包、断点和 npm 内容缓存，新安装前缀仍是全新目录，所有复用包都重新验签。

输出目录必须不存在。失败和中止报告必须保留；网络失败不可当成通过。npm 原生依赖下载曾出现域名解析失败及连接重置，已据此修复误报成功和系统代理适配。原生组件采用 1 MiB 分段下载及断点续传；主包和原生组件都校验 SHA-512 及 npm 发布签名，再将原生组件加入 npm 完整性缓存。安装后实际执行 CLI 验证。
